# SortingApp

Консольное приложение для сортировки объектов класса `Student` с использованием паттернов **Стратегия** и **Builder**. Реализована поддержка трёх алгоритмов сортировки, заполнение данных из разных источников, запись результатов в файл и многопоточный подсчёт вхождений.

## 📌 Функциональные возможности

- **Модель данных** – класс `Student` с полями:
  - `groupNumber` (int) – номер группы
  - `averageScore` (double) – средний балл
  - `recordNumber` (String) – номер зачётной книжки
- **Builder с валидацией** – проверка на положительный номер группы, балл в диапазоне [0, 5], непустой номер зачётки.
- **Заполнение коллекции** тремя способами:
  - случайными данными,
  - из текстового файла (формат CSV),
  - вручную с клавиатуры.
- **Стратегии сортировки** (реализованы вручную, без готовых библиотек):
  - пузырьковая сортировка (`BubbleSort`),
  - сортировка вставками (`InsertSort`),
  - сортировка выбором (`SelectionSort`),
  - дополнительная: сортировка только элементов с чётным номером группы (`EvenOddSort`).
- **Сравнение** по любому из трёх полей через компараторы.
- **Запись результатов** в файл в режиме добавления:
  - отсортированной коллекции,
  - количества найденных студентов по номеру зачётной книжки.
- **Многопоточный подсчёт** вхождений элемента в коллекцию (Дополнительное задание 4).
- **Кастомная коллекция** `CustomList` вместо стандартного `ArrayList` (Дополнительное задание 3*).
- **Использование Stream API** для чтения данных из файла (Дополнительное задание 3).

## 🛠️ Технологии

- Java 8 (или выше)
- Сборка через `javac` (без Maven/Gradle)
- Кодировка файлов: UTF-8

## 🚀 Инструкция по сборке и запуску

### Требования
- Установленный JDK (8 или выше)
- Команды `javac` и `java` доступны в терминале

### Сборка

```bash
# Перейдите в корневую папку проекта
cd SortingApp

# Скомпилируйте все исходники и тесты (Windows PowerShell)
$files = Get-ChildItem -Recurse -Include *.java -Path src\main\java, tests | ForEach-Object { $_.FullName }
javac -d out $files

Запуск

java -cp out Main

После запуска откроется меню:

Алгоритм сортировки. Класс: СТУДЕНТЫ 
1. Заполнить коллекцию
2. Выбрать стратегию сортировки
3. Сортировать и вывести
4. Записать результат в файл
5. Записать результат поиска (количество вхождений) в файл
0. Выход

🧪 Тестирование
Ручные тесты находятся в папке tests/ManualTests.java. Для их запуска:


java -cp out ManualTests
